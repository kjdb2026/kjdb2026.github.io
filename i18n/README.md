# 다국어 페이지 관리

- 영어 원본: 루트의 HTML 파일 10개
- 한국어: `ko/`의 동일한 파일명
- 일본어: `ja/`의 동일한 파일명
- 번역: `i18n/translations.json`
- 공통 스타일 및 메뉴 동작: 루트의 `styles.css`, `script.js`

콘텐츠를 수정할 때에는 영어 원본과 번역 목록을 함께 수정한 뒤 아래 명령을 실행합니다. Python 표준 라이브러리만 사용하며, GitHub Pages에서 별도의 서버나 번역 API 없이 동작합니다.

```sh
python scripts/localize.py
python scripts/check_localization.py
node scripts/check-navigation.cjs
```

`ko/`, `ja/`의 HTML은 생성 결과이므로 직접 수정하지 않습니다. 생성된 HTML도 함께 커밋해야 배포에 반영됩니다. 언어 선택 메뉴와 `hreflang` 링크는 생성 스크립트가 관리합니다.

번역 목록의 키는 영어 문구의 연속 공백을 하나로 정리한 값입니다. `<0>...</0>`, `<1/>` 등은 원문의 링크, 강조, 날짜, 줄바꿈을 보존하는 자리표시자입니다. 문장에 맞게 위치를 옮길 수 있지만 번호와 짝은 유지해야 합니다. 번역이 누락되거나 자리표시자가 손상되면 생성 작업이 중단됩니다.

```sh
python scripts/localize.py --inventory
```

이 명령으로 현재 번역 대상 문구를 확인할 수 있습니다. 인명은 공식 영문 표기를 유지했고, 실제 이동 시 필요한 한국어 주소와 호텔명은 일본어 페이지에서도 한국어로 병기합니다. 외부 등록폼과 관련 기관 사이트는 기존 URL을 사용합니다.

언어 선택은 현재 페이지의 다른 언어 버전으로 이동합니다. 사이트 내부 이동 시 해당 언어가 유지되며, JavaScript가 켜져 있으면 쿼리 문자열과 구역 링크도 유지됩니다. 언어 선택 메뉴와 번역된 콘텐츠 자체는 JavaScript 없이도 사용할 수 있습니다.
